This sections lists the most useful commands provided by the *dnf* utility. For a complete list of commands, options, and their syntax, see the *dnf*(8) man page.

*dnf help _command_*:: Displays detailed information about a command.
+
[source, console]
----
$ dnf help upgrade
upgrade [PACKAGE...]

upgrade a package or packages on your system
alias: update
----

*dnf check-update*:: Checks if any updates are available for all packages in the enabled repositories.
+
[source, console]
----
$ dnf check-update
Updating and loading repositories:
Repositories loaded.
Upgrades (available for reinstall, available for upgrade)
podman.x86_64 5:5.8.3-1.fc44 updates
----

*dnf provides _command_or_file_*:: Shows which package provides the specified command or file.
+
To specify a command:
+
[source, console]
----
$ dnf provides ipa-server-install
dnf provides ipa-server-install
Updating and loading repositories:
Repositories loaded.
freeipa-server-4.13.1-12.fc44.x86_64 : The IPA authentication server
Repo         : updates
Matched From : 
Filename     : /usr/bin/ipa-server-install

freeipa-server-4.13.1-9.fc44.x86_64 : The IPA authentication server
Repo         : fedora
Matched From : 
Filename     : /usr/bin/ipa-server-install
----
+
To specify a file:
+
[source, console]
----
$ dnf provides /etc/sssd/sssd.conf
Updating and loading repositories:
Repositories loaded.
sssd-common-2.13.1-1.fc44.x86_64 : Common files for the SSSD
Repo         : @System
Matched From : 
Filename     : /etc/sssd/sssd.conf

sssd-common-2.12.0-4.fc44.x86_64 : Common files for the SSSD
Repo         : fedora
Matched From : 
Filename     : /etc/sssd/sssd.conf

sssd-common-2.13.1-1.fc44.x86_64 : Common files for the SSSD
Repo         : updates
Matched From : 
Filename     : /etc/sssd/sssd.conf
----

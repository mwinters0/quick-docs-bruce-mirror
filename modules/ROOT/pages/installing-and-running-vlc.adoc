== Installing VLC

VLC depends on codecs that Fedora cannot ship by default due to licensing restrictions. Enable the RPM Fusion repositories first:

[source, console]
----
$ sudo dnf install https://download1.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm
$ sudo dnf install https://download1.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-$(rpm -E %fedora).noarch.rpm
----

Then install VLC:
[source, console]
----
$ sudo dnf install vlc
----

NOTE: Without RPM Fusion enabled, VLC still installs and runs, but many common video formats (H.264, HEVC, and others) will fail to play due to missing codec plugins.

== Running VLC

* To run the VLC media player using GUI:
+
--
. Open the launcher by pressing the _Super_ key.
. Type _vlc_.
. Press _Enter_.
--


* To run VLC from the command line:
+
[source, console]
----
$ vlc <source>
----
+
Replace <source> with path to the file to be played, URL, or other data source. For more details, see link:https://wiki.videolan.org/Documentation:Command_line/#Opening_streams[Opening streams] on VideoLAN wiki.
